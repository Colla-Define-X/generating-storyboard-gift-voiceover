# 分镜口播字幕对抗检核

交付前用以下视角检核，直接修正不合格句，只交付通过后的版本。

| 视角 | 关键问题 |
|---|---|
| 怀疑型消费者 | 卖点有商品证据吗？是否把 AI 设计画面、外观效果或文字猜测当成真实参数？ |
| 收礼人 | 关系、使用收益和寓意是否贴合？有没有承诺一定喜欢、道德绑架或价格未知却说无负担？ |
| 竞争对手 | 删除产品名后是否适用于任何礼物？能否用画面中的真实特征替换空泛形容词？ |
| 事实审核者 | 是否虚构材质、授权、优惠、库存、销量、体验或评价？道具、盒外物件是否被写成内含物？ |
| 剪辑师 | 顺序是否尊重输入？每个具体动作、部件和“这个”能否找到当前画面？是否暗中增加镜头？ |
| 配音师 | 每镜及全片是否容得下台词？有没有过长句、难读符号、读音歧义？估算是否冒充试听结果？ |
| 字幕编辑 | 纯稿能直接粘贴朗读吗？有无混入镜号、时码或舞台指令？分镜表与纯稿是否一致？ |
| 内容编辑 | 是否完整连贯而非逐格报幕？多稿是否只是同义替换？一组分镜是否误生成多条无关长稿？ |

## 判定与修复

以下问题未修复不能作为完成稿：编造产品事实；混淆概念设计与商品证据；确认不存在的配件；口播与画面矛盾；锁定时长内明显念不完；纯稿混入非朗读指令；将估算时码冒充真实同步字幕。

依次修复事实和归属、音画对应、时长负荷、口语与断行、版本差异。证据不足时删掉主张，内容太多时先删辅助卖点；不要为达标编造新细节或擅自延长镜头。

修复后重新核对逐镜台词与纯稿是否一致。无需展示打分、淘汰稿或长篇审查过程；摘要说明实际修改和真实待确认信息。没有配音试听或实际时间轴时，明确交付的是文案及估算，不能宣称已完成数字人音视频同步。
