# 分镜图驱动的文创礼赠文案框架

## 1. 分镜识别与证据层级

识别宫格边界、编号、箭头、时间码和文字标注。将镜头标作 S01、S02 等内部编号；保留原始编号映射。区分包装、开箱、全套、细节、使用、赠送、氛围、收尾镜头，不把类别缺失当成必须补拍的要求。

镜头卡字段：镜号、图中实际可见内容、用户补充内容、素材性质（实拍/概念/不明）、产品与道具归属、可见动作或计划动作、叙事作用、已给或建议时长。

静态图片不能证明动作速度、完整操作过程或功能结果；箭头和描述可以证明计划动作。AI 图里出现文字、包装槽位、配件也不能单独证明量产商品具备这些内容。

## 2. 物件归属与事实卡

将对象分为确认的核心产品、确认的配件、可能配件、场景道具、归属不明。同一物件在多个镜头反复出现，不计为多件产品；不同镜头款式有冲突时，不擅自合成一套。

证据优先参考用户明确的商品资料、清单和实际商品画面，并核对是否存在冲突。只有画面说明或概念图时，能确定的是视觉方案，产品事实仍需用户资料支持。关闭礼盒不能证明内含清单。

事实卡分三层：

- 已确认：实际画面可见或用户明确提供，注明来源。
- 策划推测：审美感受、可能人群、关系和文化联想。
- 待确认：材质、准确工艺、尺寸、价格、授权、库存、销量、配件归属及真实使用效果。

“金色”不等于金属、镀金或烫金；“皮质感”不等于真皮；文化风格不等于博物馆授权。无法辨认的图中文字不补写。

## 3. 特点、收益与痛点

为每个卖点建立链路：

`已确认特点 → 使用或赠送收益 → 真实痛点 → 支撑镜号`

例如：实际镜头确认书签夹在书页中，可连接到“记录阅读位置”。若没有底座和插入操作的证据，不扩展为“阅读与桌面摆件两用”。

可用角度包括视觉设计、文化主题、实用功能、组合搭配、礼赠仪式和日常留存。每条选一个主卖点和零至两个辅助卖点，不为了填表创造信息。

痛点优先从“不知道如何选、怕礼物闲置、表达心意太空泛、缺少兴趣适配”等具体情境推导。价格未知，不承诺便宜、划算、送礼无负担；包装内容不明，不承诺一盒配齐。

## 4. 场景与人群匹配

优先服从用户指定的场景和关系；与商品事实冲突时简述不匹配并用中性措辞。未指定时，选择与镜头主题最贴近的一个主场景：阅读自用、朋友赠礼、毕业纪念、生日、节日心意等。分析模式可补充三至五个候选及不适用理由，但不要在一条短片中塞入全部节日。

不要默认套教师节，不按颜色武断划分男女款，不承诺收礼人一定喜欢。文化寓意区分可见文字、常识性象征与策划解释，不能把自拟寓意说成官方设计故事。

## 5. 信息密度与版本差异

按视觉主题、产品组成、结构功能、确认细节、使用动作、礼赠包装归纳证据。重复特写不增加独立卖点。

信息密度决定一条片子的内容负荷，不决定默认稿数。默认一组分镜一条成片稿；用户明确给出不同视频组时每组一条。时长短或证据稀疏时减少论点，允许简短情境句或留白。

要求多版本时，建立“版本、视角、主卖点、开头类型、情感落点、支撑镜号”差异表。版本可分别偏向实用、礼赠或审美，但只有证据支持时才能成立；不能只换称呼，也不能将同一固定镜头改写成不存在的故事。

## 6. 连续口播与音画关系

选择适合既有镜头的结构，例如“情境引入 → 产品细节 → 使用收益 → 自然收尾”或“第一眼印象 → 细节解释 → 礼赠心意”。不强行填齐长篇文案的所有模块。

- 开头在现有首镜能支撑的范围内吸引注意，不写尚未出现的动作作为正在发生的事。
- 讲具体部件、图案和使用动作时对应其出现镜头。抽象情绪可以跨镜延续。
- 跨镜句在分镜表中拆为连续片段，纯稿拼接后语义完整，不重复词句。
- 静态展示也可以讲收益，不必逐格说“接下来看看”。
- 镜头留白的提示只写在剪辑提示列，纯朗读稿不含“静默两秒”。
- 若情节必须依赖未知事实，改用不依赖该事实的说法；不把整项交付卡在缺参上。

## 7. 时长预算

先用用户指定的总时长与逐镜时长。两者冲突时指出差额：能在明确约束内缩写就先给可用稿；无法同时满足时说明采用的临时方案，必要时只问哪个时长优先。

没有时长时，按镜头信息量建议分配，并说明这是文案规划，不是从静态图测出的真实时长。不要无依据套用固定三十秒或每条固定字数。

中文普通商业口播可暂用每秒三至四个汉字的粗略预算，默认约三点五字/秒，留约百分之十五时间给停顿。此数值是写作估算，不是特定数字人引擎的性能保证。数字、英文、型号按实际读出的长度估计。

`镜头可用朗读字数 ≈ 镜头秒数 × 暂定语速 × 0.85`

总量和每镜都要检查。三秒短镜通常只承载一个短意群；若一句话跨镜，按连续镜头合计预算，同时检查具体指代出现时机。超时先删套话、辅助卖点与冗余行动引导，再缩短句子。不得擅自延长用户锁定的时间，也不得用明显不自然的快读掩盖超时。

若已有合成音频，应按实际语音时长复核；只有文字时使用“预计”“建议”“待试听校准”。本技能不自动调用付费配音、生成数字人视频或导出视频。

## 8. 数字人朗读与字幕

用自然口语和完整语义，每句只表达一个主要意思。适度使用逗号、句号、问号，让引擎自然断句；避免密集感叹号、省略号、斜杠、表情符号与长串成语。

纯朗读稿把数字、单位和缩写处理为清楚的读法，例如用户确认的“99元”可写“九十九元”。不得自行改变品牌、型号或不确定读音；读音说明放在稿外。没有明确引擎要求，不输出 SSML 或情绪控制标签。

字幕按语义分行，一行一个短意群，可优先约八至十六个汉字，但不拆散专名或词组来凑字数。纯稿保留正常标点；剪辑端如果需要不同断行，另给字幕版本，不能改掉语义。

逐镜表中的朗读文字，按镜序拼接，应与纯稿一致（允许标点和换行调整）。标题、版本名、镜号、时码、语气、动作、音效和停顿指令都留在朗读块之外。

## 9. 简例

文字分镜：实拍 S01 闭合红礼盒三秒，S02 盒旁金色书签及咖啡四秒，S03 书签夹入书中五秒。用户未确认内含清单或材质。

| 镜头 | 口播片段 | 说明 |
|---|---|---|
| S01 | 给阅读，多一点仪式感。 | 不说礼盒内含什么 |
| S02 | 这一抹金色，陪着书页。 | 不说金属，不把咖啡当赠品 |
| S03 | 夹在今天读到的地方，下次接着读。 | 使用收益对应动作 |

纯朗读稿：

```text
给阅读，多一点仪式感。
这一抹金色，陪着书页。
夹在今天读到的地方，下次接着读。
```

这是基于约十二秒分镜的短稿示例，实际适配需由选定音色试听确认。若同样画面来自 AI 概念图且实际商品功能未知，应改为不承诺使用功能的文案，并在内部记录证据边界；用户只要字幕时，仅在存在影响理解的必要说明时放在稿外。
